# Archivo histórico

Estos documentos son el análisis, PRD, diseño, arquitectura, copywriting y roadmap originales, escritos **para el cliente "FUERZA"** (un obrador real de Avilés, Asturias) que dio origen a esta plantilla. Contienen su nombre comercial, ubicación y decisiones de negocio específicas.

Se conservan aquí solo como **referencia histórica** de cómo se llegó al diseño técnico actual — no describen la configuración de ningún cliente nuevo que use esta plantilla (`obrador-base`). Esa configuración vive en runtime, editable desde `/admin/configuracion/*` (ver el README del repositorio).

No se han editado ni limpiado sus referencias a FUERZA/Avilés: harían perder el valor histórico del documento sin aportar nada al template en sí.
