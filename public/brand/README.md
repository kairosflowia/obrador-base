# Assets da marca

Substitui os ficheiros mantendo os caminhos ou altera os slots em `src/config/site-config.ts`.

- `logo/`: logotipo/wordmark.
- `pwa/`: ícones instaláveis; os defaults continuam nas rotas `/icon` e `/apple-icon` do Next.js.
- `hero/`: imagem principal da Home.
- `obrador/`: espaço, processo e produção.
- `team/`: equipa e retratos.
- `institutional/`: história, localização e subscrições.
- `products/`: fallback de catálogo; fotografias reais continuam no Supabase Storage.
- `social/`: imagem Open Graph.

Os SVG `*-placeholder.svg` são fallbacks neutros e podem permanecer até existirem fotografias aprovadas.
